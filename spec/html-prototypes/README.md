# HTML prototypes

This directory is a catalogue of standalone HTML design prototypes. The
artifacts are illustrative and non-authoritative: their presence does not add
requirements, approve interactions, or demonstrate implemented behavior.

Read [the directory rules](AGENTS.md) before importing, editing, or promoting
anything from a prototype. In particular, prototype ideas require explicit
permission and are promoted one concept at a time. A prototype import by
itself is only provenance and design reference.
