# Prior art

This directory holds analyses of earlier, external solutions to problems this
repository addresses. An analysis describes how the external solution works,
what it got right, where it falls short, and how it compares with the
repository. It is reference material: it adds no requirement, approves no
design, and is not evidence of implemented behavior. Requirements that follow
from an analysis belong in the roadmap, [deferred scope](../deferred-ideas/README.md),
or the [issue catalog](../issues/README.md), linked back to the analysis.

Each analysis is named after the artifact it describes, in kebab-case. The
analysed artifact itself is not committed. Analyses keep only data that is
anonymised or synthetic and omit file metadata such as author names or paths.
