# Composed attention

## Contract

The event-derived world and its matching plan feed one pure evaluator, composed
from core checks and the compiled modules selected by the profile. Checks are
independent and immutable. Profiles provide declarations, never executable rules
supplied at runtime. Findings are computed in memory, never persisted domain state.

Each registered code owns detection, natural identity, localized copy, urgency,
provenance, areas, display scopes, actions, blockers and evidence acknowledgements.
Domain validators, the resolver and solver remain the owners of domain facts.
Severity does not determine admission or closing readiness: operation policies do.

The result contains items and coverage. Coverage distinguishes evaluated,
not-applicable and unavailable; unknown input never means not-applicable. A failed
check produces sanitized attention and incomplete coverage. An all-clear claim
requires complete coverage and an empty actionable subset.

Identity consists of code and an escaped canonical natural key. Locale, names,
copy, head sequence and evidence fingerprints are excluded. Equal identities
merge only when normalized evidence is equal. Conflicting evidence is a failed
check. Counts select the same IDs that details display.

Evidence carries typed subjects, source labels and sequence, resolver causes,
solver stage, fields, operation/group IDs, and closing facts as applicable. Copy
uses shared German and English templates with no raw-code or text-parsing fallback.
Restricted notes and hidden entities never reach general or other-audience copy.
Family and shared projections use explicit allowlists, including derived data.

## Responses and time

Requested responses are declared per control and scope. Every tri-state control
has an explicit neutral marker; an absent historical value means unknown, not
refusal or neutrality. Neutral and substantive values are mutually exclusive in
an atomic change group. Optional ordinary controls are not completeness gates.
Live label save timestamps come from envelopes, with no tombstone or history scan.
Time is explicit input; deadline refresh must not solve again.

## Readiness and review

Closing depends on explicit blockers and unavailable required checks. Workshop
review acknowledges only age/audience and missing/unavailable-leader advisories.
The fingerprint covers stable natural keys, relevant evidence and compiled build
policy; it excludes translated copy and unrelated head changes. The Worker
recomputes at the exact prefix and preserves immediate acknowledgement adjacency.

Capacity reductions use D30 at every append boundary and every lowering path:
compare exact before/after prefix plans, reject below current unique attendance
or any attendance-pair change. Replay stays structural and the narrow validation
world never solves. Closed comparisons preserve typed provenance and affected
families; historical print explanations are derived at the closing prefix.

## Acceptance

Every check has triggering, resolution, near-miss, multiplicity, applicability,
missing-input, locale, prospective and privacy fixtures. Determinism, purity,
stable identity, admission races, Worker/browser agreement, navigation, recovery,
accessible details, print and bounded work are required. All current attention
surfaces select this result; no screen owns another domain attention predicate.
